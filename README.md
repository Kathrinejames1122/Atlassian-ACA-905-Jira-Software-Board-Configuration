[![Atlassian ACA-905](https://img.shields.io/badge/Atlassian-ACA--905-0052CC?style=for-the-badge&logo=atlassian&logoColor=white)](https://www.atlassian.com/)

A dedicated study guide and knowledge reference for the **Atlassian Jira Software Board Configuration (ACA-905) Certification**, covering Jira board administration, configuration, filters, workflows, and agile planning concepts. This is a historical exam resource; Atlassian retired the certification on July 31, 2026.

---

## Exam Overview

The Atlassian Jira Software Board Configuration certification validated the ability to configure and manage Jira Software boards for agile teams. The credential focused on board types, permissions, filters, visual configuration, and Scrum estimation. The exam is retired and is no longer available for new candidates.

- **Exam Format**: Historically, a proctored examination available online or in person.
- **Target Audience**: Jira board administrators, project managers, development leads, and Scrum Masters.
- **Prerequisites**: No formal prerequisite specified; intended for Jira Software users with board administration and permission experience.

---

## Core Exam Domains & Knowledge Areas

### 1. Board Types & Concepts

- Understand Scrum and Kanban board purposes and differences.
- Identify board use cases for different agile team workflows.
- Understand how boards organize and display Jira work items.

### 2. Configuring Board Permissions & Filters

- Configure board access and filter-sharing permissions.
- Understand saved filters and their relationship to boards.
- Use Jira Query Language (JQL) to define board contents.

### 3. Configuring Board Columns & Swimlanes

- Map workflow statuses to board columns.
- Configure swimlanes to organize work items.
- Apply column settings and work-in-progress limits.

### 4. Configuring Estimation & Working Days

- Configure estimation settings for Scrum boards.
- Understand story points and time-based estimation.
- Configure working days and related planning settings.

### 5. Configuring Board Appearance

- Customize board card colors and layouts.
- Configure displayed issue fields.
- Adjust visual settings to improve work visibility.
